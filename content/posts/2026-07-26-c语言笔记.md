```c
#include <stdio.h>

int main()
{
    return 0;

```

| **多行注释** | `/* 注释内容 */` |

## 三、数据类型

| 类型 | 关键字 | 占用空间 | 说明 |
| :--- | :--- | :--- | :--- |
| **整型** | `int` / `short` / `long` / `long long` | 2 ~ 8 字节 | 存储整数 |
| **字符型** | `char` | 1 字节 | 存储字符对应的 ASCII 码值 |
| **单精度浮点型** | `float` | 4 字节 | 存储小数 |
| **双精度浮点型** | `double` | 8 字节 | 存储小数（精度更高） |
| **布尔型** | `_Bool` / `bool` | 1 字节 | 表示逻辑上的真 / 假 |
| **空类型** | `void` | 1 字节 | 表示"无类型"，主要用于函数返回值、函数参数以及通用指针 |

## 四、赋值和初始化

### 变量初始化格式

```c
<类型名称> <变量名称> = <初始值>;
```

### 示例

```c
int price = 0;
```

## 五、运算符

1.运算优先级：`+` `-` `*` `/`

2.自加：`++i` / `i++`
  
3.自减：`--i` / `i--`（只能用于变量）

## 六、数据的输入输出

1.头文件 `#include<stdio.h>`

2.格式说明符：

- 十进制: `%d` `%ld`
- 八进制: `%o` `%lo`
- 十六进制: `%x` `%lx`
- 小数: `%f`(普通) `%e`(指数) `%g`(自动选择)
- 字符:`%c`
- 字符串: `%s`
- 变量的内存地址:`%p`
- %:`%%`

3.格式输出：`printf("格式控制", 输出列表);`

   格式输入：`scanf("格式控制", 内存地址表);`

4.取地址符：`&`

>`<` `<=` `>` `>=` `==` `!=`

4.逻辑运算符
