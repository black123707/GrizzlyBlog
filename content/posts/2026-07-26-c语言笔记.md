# C 语言基础笔记

## 一、程序框架

```c
#include <stdio.h>

int main()
{
    return 0;
}
```

---

## 二、注释

| 类型 | 语法 | 示例 |
|:---|:---|:---|
| **单行注释** | `// 注释内容` | `// 这是单行注释` |
| **多行注释** | `/* 注释内容 */` | `/* 这是多行注释 */` |

---

## 三、数据类型

| 类型 | 关键字 | 占用空间 | 说明 |
|:---|:---|:---|:---|
| **整型** | `int` / `short` / `long` / `long long` | 2 ~ 8 字节 | 存储整数 |
| **字符型** | `char` | 1 字节 | 存储字符对应的 ASCII 码值 |
| **单精度浮点型** | `float` | 4 字节 | 存储小数 |
| **双精度浮点型** | `double` | 8 字节 | 存储小数（精度更高） |
| **布尔型** | `_Bool` / `bool` | — | 表示逻辑上的真 / 假 |
| **空类型** | `void` | — | 表示"无类型"，主要用于函数返回值、函数参数以及通用指针 |

---

## 四、赋值和初始化

### 变量初始化格式

```c
<类型名称> <变量名称> = <初始值>;
```

### 示例

```c
int price = 0;
```
