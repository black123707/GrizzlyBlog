## 一、定义

### 1. 指针是一种特殊的变量，它的值是某一个变量在内存中的"地址".

### 2. 从内存的角度看：

计算机每一个内存都有独特的地址.

### 3. 从变量的角度看：

① **普通变量**：用来装数据内容（例如：`int a = 10`;，变量 `a` 里装的是数字 10）.

② **指针变量**：用来装内存地址（例如：`int *p = &a`;，变量 `p` 里装的是 `a` 的"房间号"）.

## 二、指针变量的语法定义格式

```
数据类型 *指针变量名;
```

 例如

```
int *p; // 定义了一个指针变量 p，它专门用来存放一个 int 型变量的内存地址
```

① **`int`**：表示这个指针指向的数据类型（说明它存的地址里放的是一个整数）.

② **`\`***：这里的 `*` 是一个标识符，用来告诉编译器`p`是一个指针变量.

③ **`p`**：指针变量的名字.
